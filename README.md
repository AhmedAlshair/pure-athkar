# Pure Athkar

A minimal, fast web app for daily Muslim remembrance (أذكار) and supplications. Built as a Progressive Web App (PWA) so it works offline and can be installed on any device.

## Features

- **Daily Athkar** — Morning, evening, after-prayer, and sleep supplications
- **PWA support** — Installable and works fully offline
- **Lightweight** — No heavy frameworks, just Astro + Svelte

## Tech Stack

- [Astro](https://astro.build) — Static site framework
- [Svelte](https://svelte.dev) — Interactive UI components
- [vite-plugin-pwa](https://vite-pwa-org.netlify.app) — PWA support

## Getting Started

```bash
# Install dependencies
npm install

# Start the dev server
npm run dev
```

The app will be available at `http://localhost:4321/pure-athkar`.

## Scripts

| Command           | Description                  |
| ----------------- | ---------------------------- |
| `npm run dev`     | Start local dev server       |
| `npm run build`   | Build for production         |
| `npm run preview` | Preview the production build |
